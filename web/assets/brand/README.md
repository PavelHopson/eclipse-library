# Eclipse Library brand mark

Production identity based on the approved concept: an eclipse crescent that becomes an open book.

## Files

- `eclipse-library-mark.svg` - primary transparent mark for the product UI.
- `eclipse-library-mark-monochrome.svg` - one-colour fallback for documents and constrained surfaces.
- `eclipse-library-favicon.svg` - simplified mark on the dark application tile.
- `eclipse-library-logo-board-v2.png` - visual direction board generated from the original reference.

## Rules

- Keep the crescent, two page arcs and centred bookmark together.
- Use the canonical Eclipse Forge palette: `#05070A`, `#F2F5F9`, `#6BA3FF`, `#D4AF37`.
- Do not recolour the mark purple, add heavy bloom, stretch it or place text inside the symbol.
- Use the monochrome asset when colour reproduction or contrast cannot be guaranteed.
- Keep clear space around the mark equal to at least one half of the bookmark width.
- At 16-24 px use the favicon asset; do not use the larger detailed mark.

The wordmark stays as live Outfit text in the application header for sharper rendering and localisation-safe layout.
