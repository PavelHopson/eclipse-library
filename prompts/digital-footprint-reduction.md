# Сокращение собственного цифрового следа

Defensive privacy prompt только для самостоятельного аудита. Не используйте его для поиска другого человека, деанонимизации, преследования, обхода доступа или создания ложной личности.

## Перед использованием

- Лучше выполнять поиск вручную или локально.
- Не вставляйте в облачную модель пароли, документы, банковские данные, точный адрес, полные email/телефон или ответы на контрольные вопросы.
- Для поиска используйте частично маскированные идентификаторы и раскрывайте минимум данных.
- Сохраняйте подтверждения удаления локально; учитывайте законодательство своей страны.

```text
Ты — помощник по цифровой приватности. Помоги мне законно и этично сократить только мой собственный публичный цифровой след.

Регион: [СТРАНА/РЕГИОН].
Типы площадок, которыми я пользовался: [ПЛАТФОРМЫ БЕЗ СЕКРЕТОВ].
Основные риски: [ТЕЛЕФОН / СТАРЫЕ ПОСТЫ / ФОТО / DATA BROKERS / ДРУГОЕ].

Не проси пароли, документы, финансовые сведения, точный домашний адрес или иные чувствительные данные.
Не выполняй поиск по третьим лицам и не предлагай impersonation, illegal access, harassment или evasion.

Составь приоритетный план:
1) инвентаризация моих публичных профилей и документов;
2) забытые аккаунты, которые я уже назвал;
3) классификация: удалить самому / закрыть / обновить / запросить удаление / мониторить;
4) официальные формы data brokers и поисковых систем, доступные в моём регионе;
5) review social privacy и геолокационных подсказок;
6) удаление metadata из моих будущих файлов;
7) проверка моих email через официальный breach-notification сервис без передачи пароля;
8) безопасный мониторинг новых упоминаний.

Для каждого шага укажи: действие, официальный URL, какие данные придётся раскрыть,
сложность, ожидаемый privacy effect, подтверждение и дату follow-up.
Любую найденную страницу считай совпадением только после моей ручной проверки.
Будь честен: кэш, архивы и законные публикации не всегда можно полностью удалить.

В конце создай локальный tracker:
Площадка | Что раскрыто | Основание/метод | Дата запроса | Follow-up | Статус | Подтверждение
```
