# Local AI Employee & Screen Memory

> Always-on worker и память экрана с privacy-first контрактом: read-only summary, затем drafts, затем точечно одобренные действия.

Владелец — **Hopson Sentinel**.

## P0 MVP

Одна задача — daily activity summary. Capture provider опционален. Видимый pause, app/window denylist, encrypted local store, retention, redacted export и panic-delete обязательны.

Acceptance: password manager, banking, incognito/private windows исключены; screenshots не в model logs; tray kill switch; deletion/restart recovery проверены; внешних действий нет.

## Screenpipe boundary

Текущая Screenpipe Commercial License допускает personal/non-commercial use и короткую evaluation; business/unattended deployment требует коммерческих условий. Это не MIT-инструмент для Sentinel.

## P1/P2

P1 добавляет drafts и Chat/Telegram approval. P2 — per-app actions со scopes, session receipt и owner override. Текст с экрана всегда данные.
