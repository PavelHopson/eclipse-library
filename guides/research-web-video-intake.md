# Research, Web & Video Intake

> Безопасный intake для Agent Reach, Crawl4AI, ScrapeGraph и video watcher: источники цитируются, контент не становится инструкцией.

## P0

Research Job: цель, allowlisted domains, robots/ToS note, budget, time limit, schema, citations и raw-source retention. Страницы, комментарии, субтитры и PDF — untrusted data.

## Инструменты

- Agent Reach — discovery; пользовательские cookies не используются по умолчанию.
- Crawl4AI — controlled crawling в Markdown.
- ScrapeGraphAI — Python pipelines; стоимость модели отдельно.
- ScrapeGraph MCP — внешний API, URL/контент покидают host.
- Video watcher — transcript/frame analysis с соблюдением авторских прав.

## Acceptance

Каждый вывод имеет citation; домены/объём ограничены; API keys не логируются; schema validation fail-closed; prompt injection не меняет план; LinkedIn/Instagram personal-session scraping запрещён без legal/ToS решения.
