# Open-source Replacement Matrix

> «Открытый исходный код» не означает бесплатную эксплуатацию или полную замену SaaS: фиксируем функции, лицензию, TCO и migration gap.

## Проверенная пятёрка

| Ресурс | Сравнение | Реальность | Eclipse |
|---|---|---|---|
| Twenty | Salesforce/CRM | core в основном AGPL, Enterprise/MIT части отдельно | StarCRM reference |
| Voicebox | voice studio | MIT app, model licenses/consent отдельно | Media/Chat pilot |
| Crawl4AI | Apify-like crawling | open crawler, target ToS сохраняются | AI Hub adapter |
| NocoDB | Airtable-like DB | Sustainable Use, не permissive OSS | internal sandbox |
| Open Design | AI design workbench | Apache-2.0; cloud model может получать context | design pilot |

## Другие кандидаты

Cal.com, Nextcloud, n8n, PostHog, Bitwarden, Chatwoot, Penpot и Baserow требуют отдельных TCO/migration исследований. «Заменяет» допустимо только после parity test.

## Acceptance

Canonical source, exact version, license, hosting, backup, upgrade path, data residency, migration/exit plan и три missing capabilities. Никакой production migration из карточки Library.
