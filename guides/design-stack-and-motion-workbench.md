# Design Stack & Motion Workbench

> Taste, Playwright, Open Design, 21st.dev и motion references без копирования чужого UI и без превращения рабочих экранов в маркетинговый аттракцион.

## Процесс

1. Зафиксировать brief, tokens и запрещённые паттерны.
2. Использовать The Taste и design system проекта.
3. Искать direction в Open Design, 21st.dev, Refero, shadcn, Vivid Sites.
4. Реализовать оригинальный компонент.
5. Playwright QA: desktop/mobile, keyboard, focus, loading/empty/error/success, reduced motion.

## Применение

- Eclipse Forge landing: аккуратная доработка без смены идентичности.
- Eclipse Chat/CRM/admin: quiet, dense, task-focused; без декоративных 3D-стеков.
- Library Animation Lab/Media: выразительные 3D/motion previews с pause, reduced-motion и download pack.

## Acceptance

Нет overflow/horizontal scroll; 3-second test; целевой FPS; JS failure не блокирует задачу; download pack содержит source, license, checksum и README.
