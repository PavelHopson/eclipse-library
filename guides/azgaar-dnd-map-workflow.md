# Azgaar + Eclipse DnD Forge: понятный путь от мира к кампании

> Проверенный workflow для мастера: Eclipse DnD Forge готовит бриф, официальный Azgaar создаёт и редактирует карту, а Minimal JSON возвращает выбранные города в граф кампании. Чужой runtime, iframe, API key и автоматическая публикация не нужны.

Проверено: **3 августа 2026 года**. Официальные источники: [веб-приложение](https://azgaar.github.io/Fantasy-Map-Generator/), [GitHub repository](https://github.com/Azgaar/Fantasy-Map-Generator), [Quick Start](https://github.com/Azgaar/Fantasy-Map-Generator/wiki/Quick-Start-Tutorial), [license](https://github.com/Azgaar/Fantasy-Map-Generator/blob/master/LICENSE).

## Что это простыми словами

Azgaar’s Fantasy Map Generator создаёт не только красивый фон. Он моделирует мир: сушу и высоты, биомы, государства и провинции, культуры и религии, города, реки, дороги, маркеры и другие слои. Всё это можно менять вручную.

Для D&D это полезно в трёх ситуациях:

- мастер начинает новую кампанию и хочет получить основу мира за минуты;
- игрокам нужна понятная карта государств, дорог и известных городов;
- существующие заметки Eclipse DnD Forge нужно превратить в карту, не перепечатывая список локаций вручную.

Azgaar работает в браузере и не требует установки. Созданные карты можно использовать бесплатно, в том числе коммерчески. Исходный код опубликован под MIT; официальный license отдельно называет карты, изображения, screenshots и videos разрешёнными производными материалами.

## Что уже внедрено

На вкладке **«Мир и локации»** Eclipse DnD Forge появляется действие **«Карта мира»**.

1. Панель собирает короткий бриф из названия кампании и уже известных локаций.
2. Кнопка **«Открыть Azgaar»** открывает только фиксированный официальный HTTPS-адрес в новой вкладке.
3. Мастер создаёт или правит карту и сохраняет рабочий `.map` через `Save → Machine`.
4. Для обмена данными мастер выбирает `Export → JSON → Minimal`.
5. DnD Forge проверяет размер и структуру JSON, показывает название карты, число найденных мест, дубли и точное количество новых локаций.
6. Только после явного подтверждения города добавляются в граф кампании.

По умолчанию импортируются значимые места: столицы, порты, укреплённые города и самые населённые поселения. Это защищает интерфейс от сотен случайных узлов. Расширенный режим ограничен безопасным максимумом.

## Почему не iframe и не копия генератора

Встраивание всего приложения внутрь DnD Forge не даёт ценности, пропорциональной риску:

- upstream быстро развивается, поэтому приватный fork будет дорого синхронизировать;
- iframe создаёт неясную границу фокуса, cookies, storage и доступности на mobile;
- полный runtime добавляет ещё одно dependency tree и заметно увеличивает bundle;
- Eclipse нужен campaign workflow, а не второй картографический редактор.

Разделение ответственности проще: Azgaar рисует и хранит редактируемую карту, Eclipse DnD Forge управляет локациями, персонажами, сессиями и последствиями.

## Безопасный импорт

JSON считается недоверенным, даже если файл выглядит знакомо.

- Принимается только `.json` ограниченного размера.
- Поддерживается официальный объект `pack.burgs` из Full или Minimal JSON; `.map` не исполняется и не разбирается.
- Названия обрезаются до разумной длины и выводятся React-текстом, без HTML.
- Координаты и population должны быть конечными числами.
- Удалённые поселения и элементы без названия пропускаются.
- Совпадения с существующими локациями сравниваются без учёта регистра и не добавляются повторно.
- Preview не меняет кампанию; изменение выполняет отдельная кнопка с точным числом новых узлов.

## Ограничения, которые важно знать

- Seed воспроизводит генерацию при одинаковых параметрах, но не сохраняет ручные изменения. Для продолжения нужен `.map`.
- Browser storage может быть очищен. Официальный tutorial рекомендует хранить `.map` на машине и делать резервные копии.
- Большое число cells и тяжёлые слои требуют много ресурсов. Для первого прохода достаточно 10K cells.
- PNG, JPEG и SVG — изображения, их нельзя загрузить обратно как редактируемую карту.
- Dropbox, Google Translate, внешние fonts/images и другие optional integrations передают данные соответствующим третьим сторонам. Для приватной кампании их можно не включать.
- Импорт городов не переносит всю географию, маршруты и политические связи. Это осознанный первый срез.

## Когда считать следующий этап успешным

- новый мастер проходит путь без инструкции длиннее трёх шагов на экране;
- preview точно сообщает imported, duplicate и skipped/merged counts;
- импорт 24 значимых городов занимает меньше минуты;
- повторный импорт того же файла добавляет **0** дублей;
- malformed или oversized JSON не меняет кампанию;
- desktop и mobile не получают horizontal overflow;
- ни один внешний URL, script или API key не попадает в DnD bundle.
