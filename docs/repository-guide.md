## С чего начать

1. Откройте [README](<../README.md>): в нём остаются подробности установки и эксплуатации.
2. Определите нужный компонент по карте ниже. Для первого запуска используйте отдельную локальную среду и демонстрационные данные.
3. Проверьте зависимости, переменные окружения и стоимость внешних провайдеров. Значения ключей не переносите в README, issue или prompt.
4. Запустите только нужный компонент; миграции, фоновые сервисы и публикация не являются частью обычного просмотра проекта.

## Запуск и проверка

У проекта нет стандартного набора корневых npm-команд. Используйте команды своего стека из [README](<../README.md>); не подменяйте их универсальным Vite-шаблоном.

Перед принятием изменения проверьте: запуск нужного компонента, основной сценарий, ошибочный ввод, восстановление после ошибки и отсутствие секретов в diff. Сборка сама по себе не доказывает работоспособность пользовательского сценария.

## Границы и права

Карточка в библиотеке не означает одобрение установки. Лицензия, источник и допуск для агентов проверяются отдельно.

Файл LICENSE/COPYING в корне при этом обзоре не найден. Публичная доступность кода не означает разрешения на любое использование; новая лицензия автоматически не добавлялась.

## Как вносить изменения

Сохраняйте существующие соглашения репозитория. Работайте над одной задачей, прикладывайте проверяемый результат и явно различайте локальную реализацию, тестирование и публикацию. Для AI-разработки в экосистеме применяется Codex; сторонние prompts и материалы не становятся активными правилами автоматически.

Оформление проверено по структуре файлов 2026-09-08. Актуальные версии, release-статус и доступность сервисов проверяются в самом проекте.
